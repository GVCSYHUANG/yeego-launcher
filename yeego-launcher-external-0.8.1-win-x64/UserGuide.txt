yeego launcher External 0.8.1

打开「App」文件夹中的「YeegoLauncher.External.exe」。
需要 Windows x64、.NET 10 Desktop Runtime 和 Microsoft Edge WebView2 Runtime。
WebView2 Runtime 官方下载：https://developer.microsoft.com/microsoft-edge/webview2/

中文路径启动修复
0.7.3 修复 Java 参数文件编码不匹配导致的 NeoForge / Forge 主类加载失败，以及启动报错乱码。
已用当前 Better MC [NEOFORGE] BMC5 的实际配置通过主类加载 dry-run 检查；此检查不执行游戏主函数。
更新后直接启动已安装的整合包即可，无需重新下载安装整合包。
中文路径按系统代码页正确传入 Java；若路径含当前代码页无法表示的表情等字符，会明确提示处理，不再静默损坏路径。

Forge / NeoForge 安装修复
现在由启动器预先下载并校验安装器所需依赖，再运行官方安装器。下载重试会复用校验通过的文件。
0.7.2 已实际安装验证 Minecraft 1.21.1 / NeoForge 21.1.176，最终必需文件检查通过。
旧版报错后可重新安装原整合包；无需删除现有游戏与缓存。
完整安装日志在游戏目录的 .yeego/loader-logs 中，失败提示会显示具体日志文件位置。

版本识别与补全
版本库现在显示正在扫描的游戏目录和扫描结果。点击「选择游戏目录」可直接选择 .minecraft、其上级目录、versions 或具体版本文件夹。
只有 JAR 而缺少同名 JSON 的版本也会显示为「下载未完成」。选中后点击「补全原版文件」，从官方来源补齐描述、运行库及资源；已校验文件复用。
刷新只读取当前显示的目录，不会自动切换到其他游戏目录。

模组下载
侧栏「模组下载」选择已有实例，自动匹配 Minecraft 版本与加载器；输入名称搜索 Modrinth，留空查看热门模组。
选择具体版本，点击「安装模组与必需前置」，完成后下次启动此实例即可加载。
支持 Fabric、Quilt、Forge、NeoForge，纯原版需要先安装加载器。
已有不同版本的同 ID 模组会提示先备份并移走，不自动覆盖；支持取消并清理未完成的新增文件。
详细步骤和兼容性说明见「ModDownloads.txt」。

身份切换与离线皮肤
右上角直接选择「离线 / 正版」，分别记住离线玩家名和微软账号。
选择正版后仍需在「账号与正版」登录并核验 Java 版资格；状态显示在按钮下方。
离线模式下，首页右侧点击「上传皮肤」选择 PNG，再选择「宽臂 / 细臂」。下次离线启动游戏时自动使用。
点击「默认」恢复离线默认皮肤。正版模式继续显示微软账号皮肤。
按住鼠标左键拖动旋转，滚轮缩放，双击模型或点击 ↺ 重置视角。
皮肤只保存在本机，不会修改微软账号皮肤；好友客户端不会自动同步看到。进入正版服务器请切换正版模式。
PNG 支持 64×64、64×32 及同比例整数倍尺寸，不超过 1 MB、边长不超过 1024；导入时转成标准尺寸。64×32 使用宽臂。
随程序附带的 Components 文件夹为离线皮肤组件，请一并保留；首次使用不需要联网下载组件。
已验证 Minecraft 1.21.11 的实际皮肤接口，其他版本或皮肤模组需要实际测试兼容性。

更新
先关闭旧 External 版本，再将新版 ZIP 解压覆盖原来的「App」文件夹。
保留原有 data-external、.minecraft 和 runtime 文件夹，账号、游戏和 Java 不需要重新安装。

0.4.1 已修复登录后「外源账号加密缓存保存失败」的数据序列化问题，以及误报目录写入权限的提示。更新后直接重新登录，已有配置与缓存保留。

登录
「账号与正版」默认使用「外源认证组件 · CmlLib」。点击「外源组件登录 / 切换账号」，在弹出的微软页面中登录自己的账号。
认证组件使用其公开默认的 Minecraft 应用身份；这不代表 yeego launcher 自有应用的 API 申请已经获批。
登录完成后还要通过 Minecraft 官方 Java 版资格和档案检查，才能以正版身份启动。
此版没有使用真实账号完成登录联调，实际登录结果以微软、Xbox 和 Minecraft 服务返回为准。

切回自有应用
在同一页面的「登录来源」选择「yeego 自有应用」，确认应用 ID，重新登录即可。
自有应用 ID 已预置；回调和审批操作见「MicrosoftLoginSetup.txt」。两个来源的账号缓存分开。

隔离
本版自己的配置、账号和浏览器数据在程序旁的 data-external 中。
首次默认游戏目录是程序旁的 .minecraft；可自行选择已有游戏目录。
Java 自动下载到程序旁的 runtime 中。
主版本没有被覆盖，也没有复制主版本的账号、Cookie 或配置。

下载与安装
保留原版游戏、Fabric / Quilt、Modrinth 整合包、本地整合包和 Java 自动安装功能。
步骤详见「DownloadsAndModpacks.txt」「JavaSetup.txt」。

分享
可以分享 External 版本 ZIP。若复制已经使用过的「App」目录，请先移除其中自己的 data-external，再交给朋友，朋友登录自己的账号。
第三方认证组件及许可在「licenses」内，发布时请一起保留。

0.7.4 修复 Forge / NeoForge 整合包启动时原版 JAR 重复进入模块层造成的 ResolutionException。无需重装整合包或删除模组。

0.7.5 兼容 Modrinth 整合包清单文件大小与实际文件不一致的情况：仅在指定 SHA512 完全匹配时接受，并记录大小差异；错误哈希仍拒绝。下载报错显示具体失败原因。

0.7.6 自动补齐整合包额外模组与资源包：识别 missing_mods_checker.json，新安装完成前和已有实例启动前处理；也可在版本库点击「补齐整合包」。按指定版本从官方入口下载，缓存记录 SHA256，复制前再次校验；未补齐则显示具体文件和详细清单路径，不会误报安装成功。
CurseForge 官方接口没有提供哈希时，使用 HTTPS 来源、准确文件编号/文件名、官方大小和归档结构检查，并记录本地 SHA256；本地缓存哈希不冒充作者发布的校验值。来源不允许自动下载或官方页面无法解析时会报告待补项。

0.7.7 支持 CurseForge 清单 ZIP：在「下载与安装 → 本地导入」选择原始 ZIP；自动安装清单指定的 Minecraft、Forge/NeoForge/Fabric/Quilt 和文件版本，并应用 overrides 配置。资源包与光影包分类安装。可选文件由「包含可选文件」控制，来源拒绝或文件不可用时列出项目/文件编号，不发布不完整实例。

CurseForge 清单指定文件的下载入口返回 404 或服务端故障时，会尝试相同文件编号和文件名的 CurseForge 官方 CDN；来源明确拒绝权限时不切换。语言支持组件（例如 KotlinForForge）可随整合包正常安装，不要求每个 JAR 都具有普通模组标识。

0.7.8 历史文件元数据兼容：网页接口返回空数据或 404 时，可用 Curse Maven 公开诊断接口解析同一项目/文件编号的原始官方 CDN 地址；0.7.8 的此恢复路径下载自官方 CDN；其它来源的回退规则见 0.7.9 说明。仅接受严格匹配文件编号目录的官方 HTTPS 地址，记录解析来源和下载来源，权限拒绝及真实编号错误不触发此恢复。

0.7.9 自动查找其它来源：
- Modrinth 整合包清单中的全部地址失败时，按原 SHA512 查询 Modrinth 的同一文件；CurseForge CDN 地址也会在三个官方节点间回退，所有候选必须通过原 SHA512 校验。
- CurseForge 整合包先尝试官方入口、mediafilez / edge / media 官方 CDN；若官方元数据提供 SHA1，或之前成功下载留下了本地哈希凭据，再按同一内容哈希查询 Modrinth。模组 JAR 还可回退到 CurseMaven 的固定项目编号/文件编号地址，并验证已知哈希。
- CurseMaven 是第三方服务，与 CurseForge 无关联；第三方只作为最后回退，不会根据相似名称选择其它版本。首次安装且无已知哈希时，不从其它平台下载无法确认内容的同名文件。
- 缓存凭据新增 SHA512，并记录实际来源；缓存丢失后可用原凭据校验重新下载的文件。哈希凭据用于内容一致性，不能代表作者数字签名。
- 连接异常、请求超时、404、429、服务器错误或内容校验失败可尝试其它来源；明确的权限拒绝不会被当成网络故障。用户取消立即停止，不再开始换源。
- 安装页面显示换源进度，运行日志记录切换与成功信息。全部来源都失败时保留缺失清单，不会假装安装完成。
0.8.0 按钮文字与全局拖入安装：
- 亮绿色按钮统一使用黑色文字，修复纯文字按钮被全局白色 TextBlock 样式覆盖的问题；深色区域仍按各自文字颜色显示。
- 将一个本机 .mrpack 或整合包 .zip 文件拖入启动器任意页面，松开后自动识别、切换到「下载与安装 → 本地导入」并开始安装，无需再点安装按钮。
- 使用当前「安装目录」和「包含整合包的可选客户端文件」选项；按包名新建隔离实例，同名自动添加 (2)、(3) 等后缀，已有实例不被覆盖。
- 支持 Modrinth、CurseForge 清单及完整客户端 ZIP，继续使用已有校验、自动补齐和自动 Java 流程。一次接收一个文件；任务进行中拒绝新的拖入，可使用「取消安装」停止。
