yeego launcher External 0.7.0 — 模组下载

1. 打开侧栏「模组下载」，选择已安装的游戏实例。
2. 检查 Minecraft 版本。加载器从实例识别，支持 Fabric、Quilt、Forge、NeoForge。
3. 输入模组名搜索 Modrinth；留空查看热门模组，列表下方可以翻页。
4. 选择模组与具体版本，点击「安装模组与必需前置」。
5. 下载完成后下次启动所选实例，加载器将读取 mods 文件夹中的模组。

纯原版不能加载这些模组，请先在「下载与安装」中安装 Fabric / Quilt，或导入带加载器的整合包。特殊整合包无法自动识别 Minecraft 版本时，手动填写其实际版本号。

安装位置
以所选实例和「启动设置」中的版本隔离设置为准，上方会显示完整 mods 路径。
受实例自身隔离配置保护的版本始终独立安装；关闭全局隔离且实例未强制隔离时，使用游戏根目录共用的 mods。
这里不会使用整合包下载页临时选择的其他安装目录。

必需前置
递归下载 Modrinth 标记的必需依赖，匹配相同 MC 与加载器；优先使用正式版，遵守指定的前置版本。
可选和已嵌入的前置不自动添加。缺少匹配版本、循环或冲突时停止，避免安装不完整的组合。
匹配版本与加载器不能保证所有模组彼此兼容，实际兼容性以游戏运行和作者说明为准。

已有模组
先校验并暂存本次全部文件，再添加到 mods。
同名且校验一致的文件直接复用，不重复下载；不同版本使用同一模组 ID 时，会提示先备份并移走旧文件，不自动删除或替换。
「打开 mods」可定位文件；本版暂不提供一键升级或卸载。
取消或失败时清理本次未完成的新增文件，已有模组保留。安装时关闭窗口会先取消清理，再退出。

来源与验证
只接入公开的 Modrinth 客户端模组，不需要提供账号令牌或 API Key；文件校验 SHA512 与大小。
暂不支持 CurseForge。项目页面按钮可以查看作者的完整说明、依赖与许可。
已真实下载验证 MC 1.21.11 / Fabric 的 Mod Menu 及两个必需前置；其他版本、加载器和模组组合需按实际游戏情况验证。
