yeego launcher 0.4.0 — Java 自动安装

默认已开启，无需提前手动安装 Java。
启动游戏、下载完游戏 / 整合包，以及运行 Forge / NeoForge 安装器时，会检查对应的 64 位 Java。

版本选择
自动模式按游戏描述中的 Java 主版本匹配，例如 Java 8、17、21、25。
本机已有对应版本时优先复用，并在使用前重新检测。
只有更高版本时，自动模式仍会安装游戏要求的主版本，减少老游戏和模组兼容性问题。
若你手动选中了满足最低要求的更高版本 Java，则尊重这个选择。

下载和安装
1. 从 Eclipse Adoptium 官方 API 查询 Windows x64 Eclipse Temurin 发行包。
2. 优先使用 JRE；对应 JRE 不可用时尝试 JDK。
3. 从 Adoptium 官方 GitHub 发布仓库下载 ZIP，显示 MB 进度。
4. 校验文件大小与 SHA256；检查 ZIP 路径、链接及重复条目。
5. 解压到临时目录并运行 java -version，确认实际主版本和 64 位环境。
6. 发布到 runtime 目录并保存记录，自动继续原来的启动或安装操作。

存放位置
启动器所在目录\runtime\temurin-主版本-摘要\...
runtime\.managed 保存运行时记录；runtime\.cache 保存已校验的压缩包。
无需管理员权限，不修改 PATH、JAVA_HOME，也不覆盖系统安装的 Java。
请把启动器放在自己有写入权限的普通文件夹中。

取消和重试
启动前的 Java 准备可点「取消 Java 准备」；整合包安装中可点「取消安装」。
取消后不启动游戏、不使用半成品 Java，保留完整且已校验的下载包供重试。
未完成的单个压缩包会重新下载；不支持分段断点续传。
游戏已安装完成、只剩 Java 准备时，取消会保留游戏，下次启动再检查。
已安装的 Java 被删除或损坏时，会重新准备并发布到新目录，保留旧目录。
首次安装需要访问 api.adoptium.net、github.com 和 GitHub 资源下载域名。
下载失败会显示原因，可检查网络后重试，或手动添加已安装的 Java。

设置
「启动设置」→「Java 环境」：
- 「缺少对应 Java 时自动下载安装（推荐）」：默认开启，可关闭。
- 「检查并准备所选版本的 Java」：提前准备当前游戏需要的环境。
- 「添加 Java…」：手动选择 java.exe 或 javaw.exe。
关闭自动下载后仍会复用已安装的运行时；缺失时会提示手动添加或重新开启。

验证
38 项自动断言覆盖官方元数据、主版本匹配、SHA256、取消、修复、缓存、并发及 ZIP 安全。
